IMAGES DES OBJETS
=================

Depose ici les images des objets du jeu. Le jeu cherche automatiquement
un fichier nomme d'apres l'objet :

    assets/items/<nom>.png      (ou .jpg / .jpeg)

Tant qu'aucune image n'existe pour un objet, le jeu affiche un "?" avec le
nom dessous. Des que tu ajoutes le bon fichier (meme nom), il s'affiche
PARTOUT : inventaire, mains, recettes de craft, sac a dos, silhouette
d'equipement. Aucun code a modifier.

EXEMPLE
-------
Pour donner une image a la veste de feuille :

    1. dessine / recupere ton image (PNG carre, fond transparent) ;
    2. renomme-la exactement    Veste_De_Feuille.png
    3. depose-la dans           assets/items/
    4. pousse le projet sur GitHub (envoyer-sur-github.bat)
    5. le prochain APK affichera l'image a la place du "?"

Le nom du fichier doit reprendre EXACTEMENT le nom interne de l'objet :
memes majuscules, memes underscores, sans accent.

----------------------------------------------------------------
LE DOSSIER futur/
----------------------------------------------------------------
assets/items/futur/ garde les images qui n'ont PAS encore d'objet dans
le jeu. Elles y sont ignorees : le jeu ne regarde que assets/items/.
Chacune porte deja le nom que l'objet devrait avoir, donc le jour ou la
recette existe il suffit de remonter le fichier d'un dossier.

    Arc.png              Echelle.png        Marteau.png
    Baie_Bleue.png       Epieu.png          Oeuf.png
    Branche_Morte.png    Four.png           Peau.png
    Canne_A_Peche.png    Fourrure.png       Torche.png
    Conque.png           Griffe.png         Viande.png

Variantes d'objets qui ont deja une image (au cas ou tu prefererais
l'une d'elles) : Hache_2, Long_Stick_2, Brown_Mushroom_2,
Red_Mushroom_2, Viande_2.

----------------------------------------------------------------
CONSEILS
----------------------------------------------------------------
- Format conseille : PNG a fond transparent, 512 px sur le plus grand
  cote. C'est la taille des images deja en place.
- Detoure bien : recadre sur l'objet, sans grande marge vide, sinon il
  parait tout petit dans sa case.
- Attention aux filigranes du genre "Made with AI" : ils font partie de
  l'image et s'afficheraient dans le jeu. Efface-les avant.
- Un fond BLANC n'est pas un fond transparent : il s'afficherait comme
  un carre blanc autour de l'objet. Il faut le detourer.
- L'image garde ses proportions, aucune deformation a craindre.
- Dans le sac a dos, une case fait environ 185 px de large : evite les
  details trop fins, ils seront illisibles.
- Le "?" n'est pas un bug : c'est l'affichage de repli quand l'image
  manque.

La liste complete des objets et des recettes est dans : src/items.py
