IMAGES DES OBJETS
=================

Depose ici les images des objets du jeu. Le jeu cherche automatiquement
un fichier nomme d'apres l'objet :

    assets/items/<nom>.png      (ou .jpg / .jpeg)

Tant qu'aucune image n'existe pour un objet, le jeu affiche un "?" avec le
nom dessous. Des que tu ajoutes le bon fichier (meme nom), il s'affiche
PARTOUT : inventaire, mains, recettes de craft, sac a dos, silhouette
d'equipement. Aucun code a modifier.

EXEMPLE
-------
Pour donner une image a la veste de feuille :

    1. dessine / recupere ton image (PNG carre, fond transparent) ;
    2. renomme-la exactement    Veste_De_Feuille.png
    3. depose-la dans           assets/items/
    4. pousse le projet sur GitHub (envoyer-sur-github.bat)
    5. le prochain APK affichera l'image a la place du "?"

Le nom du fichier doit reprendre EXACTEMENT le nom interne de l'objet :
memes majuscules, memes underscores, sans accent.

CONSEILS
----------------------------------------------------------------
- Format conseille : PNG carre a fond transparent (256x256 suffit).
- L'image garde ses proportions : une image carree evite les surprises.
- Dans le sac a dos, une case fait environ 185 px de large : evite les
  details trop fins, ils seront illisibles.
- Le "?" n'est pas un bug : c'est l'affichage de repli quand l'image
  manque.

La liste complete des objets et des recettes est dans : src/items.py
