IMAGES DU PERSONNAGE (Character)
================================

SYSTEME HUD : UNE IMAGE PAR ETAT du joueur. Chaque image est un PNG
plein ecran (les mains sont deja positionnees au bon endroit dans
l'image, le reste est TRANSPARENT).

L'image est affichee en PRESERVANT son aspect ratio et alignee au BAS
du widget (la largeur prend toute la largeur d'ecran, la hauteur est
derivee de l'aspect de l'image).

----------------------------------------------------------------
ETATS et IMAGES ATTENDUES
----------------------------------------------------------------
    HandIdle.png   -> Main VIDE, au repos
    HandHUD.png    -> Main qui TIENT un objet (paume ouverte)
    HandEx1.png    -> Etat 'ex1' : exploration phase 1 et 3 (debut/fin)
    HandEx2.png    -> Etat 'ex2' : exploration phase 2 (milieu)

----------------------------------------------------------------
GANTS : DES MAINS QUI CHANGENT D'APPARENCE
----------------------------------------------------------------
Une paire de gants PORTEE remplace l'image des mains. Le fichier porte le
meme nom, avec un SUFFIXE :

    HandIdleFeuille.png   -> repos,        gants de feuille
    HandHUDFeuille.png    -> paume ouverte, gants de feuille

Le suffixe est declare dans GLOVE_SUFFIX (src/widgets/player_hands.py), qui
fait le lien avec le nom de l'objet ("Gant_De_Feuille" -> "Feuille").
Ajouter une autre paire ne demande donc qu'une ligne et des images.

Une image gantee ABSENTE n'est pas une erreur : le jeu reprend simplement la
main nue. C'est ainsi que fonctionnent aujourd'hui les images d'exploration
(HandEx1/Ex2), qui n'ont pas de version gantee -- les gants disparaissent
donc le temps de l'animation. Pour y remedier, il suffit de deposer
HandEx1Feuille.png et HandEx2Feuille.png.

CALAGE (le point qui compte vraiment) : la main gantee doit se poser
EXACTEMENT sur la main nue -- meme taille, meme milieu, meme hauteur de bout
des doigts. Sinon les mains SAUTENT au moment ou le joueur equipe les gants,
et l'objet tenu, dessine a une position fixe (HAND_FX / ITEM_FY), ne tombe
plus dans la paume.

AU REPOS, CHAQUE MAIN A SA POSE. Le jeu ne choisit pas une image pour
les deux mains, mais une par main :
- main vide            -> HandIdle
- main qui tient       -> HandHUD (l'objet se pose dans le creux de la
                          paume, voir plus bas)
Les deux mains sont donc TOUJOURS visibles au repos. Comme chaque image
contient les deux mains, le jeu n'en prend que la moitie utile : les
mains doivent donc rester CHACUNE DE SON COTE du milieu de l'image.

PENDANT UNE EXPLORATION, le jeu CYCLE entre les 3 images :
- 1/3 du temps au debut    -> HandEx1
- 1/3 du temps au milieu   -> HandEx2
- 1/3 du temps a la fin    -> HandEx1
Apres l'exploration, retour automatique a 'haut'.

PENDANT L'EXPLORATION : les OBJETS TENUS, le bouton "Deposer" et le
LABEL nom-de-l-objet sont CACHES (animation propre, sans distractions).
Ils reapparaissent une fois l'action terminee.

D'autres etats peuvent etre ajoutes dans HUD_IMAGES de
src/widgets/player_hands.py (ex. 'craft' pour la fabrication, etc.).

----------------------------------------------------------------
CONSEILS POUR LES IMAGES
----------------------------------------------------------------
- Format : PNG, fond TRANSPARENT.
- Taille de reference : 2340 x 1080 (landscape) ou un autre format,
  peu importe : l'aspect ratio est PRESERVE a l'affichage.
- Les MAINS doivent etre dessinees dans le BAS de l'image.
- COHERENCE entre images d'un meme groupe (ex. HandEx1/Ex2) : les
  mains au MEME endroit dans toutes les images, sinon l'animation
  saute. Recommande : meme dimensions + positions identiques.
- Le fond doit etre VRAIMENT TRANSPARENT, pas blanc : un fond blanc
  recouvrirait tout le decor. Detoure en partant des BORDS de l'image,
  pas au seuil de clarte, sinon les reflets clairs de la peau se
  trouent.
- Efface les filigranes du genre "Made with AI" : ils font partie de
  l'image et s'afficheraient en plein ecran.
- Verifie qu'aucun trait ne traverse le bas (bord de table, ombre
  portee sur toute la largeur) : il deviendrait une barre en travers
  de l'ecran.
- Apres ajout : pousse le projet (envoyer-sur-github.bat) pour que
  les images soient incluses dans l'APK.

----------------------------------------------------------------
POSITIONNEMENT DES OBJETS TENUS
----------------------------------------------------------------
Quand le joueur tient un objet (ex. une pierre), il est dessine
AU-DESSUS du HUD a la position des mains. Les valeurs par defaut
(mesurees sur HandHUD.png) sont en haut de player_hands.py :

    HAND_FX = (0.346, 0.654)  -> X des centres des paumes gauche/droite
                                  (fraction de la LARGEUR du widget)
    ITEM_FY = 0.225            -> Y du creux des paumes (fraction de la
                                  HAUTEUR du widget depuis le bas)

Si les nouvelles images placent les mains a un endroit different,
ajuste ces 2 constantes dans src/widgets/player_hands.py.

Logique : src/widgets/player_hands.py
